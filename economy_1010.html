TeXの話題だと大きすぎるので、別スレを立てる価値はあるかもしれない。
苺経済板にTeX初心者用スレがあってもいいなとは思っていたし。

それとは別に、>>1氏の環境がどうか知らないけど、自分がアドバイスするならば、
やっぱりこの機会にLinux入れて使ってみれば？ということ。その上で、

(La)TeX + GNUPLOT + tgif

この３つの組み合わせ。これ最強。GNUPLOTは簡単な数値計算プログラムで
tgifはドロー系作図プログラム。これらを使えば、例えば、

１．GNUPLOTで sin(x*y) を計算しての３次元グラフを描画
２．tgif形式へ出力し、tgifで整形したりテキスト追加したり
３．PS形式で出力、LaTeX に張り込んでテキスト・図ごと印刷

なんてことが一瞬でできちゃう。ただし、最近のLinuxのパッケージには
ついてないこともあるので、下のページなどを参考にされれればよろしかろう。
お試しあれ。

GNUPLOT
http://t16web.lanl.gov/Kawano/gnuplot/

tgif
http://www.tobata.isc.kyutech.ac.jp/~daisuke/Manu/tgif/

GNU Octave は gnuplot のフロントエンドとして使うことができる。
GNU Octave や gnuplot は Linux でも Windows でもどちらでも使える。
GNU Octave で適当に数値計算して、そのままグラフに表示。
gnuplot の出力を LaTeX 向きの形式にして LaTeX でグラフを印刷することもできる。

GNU Octave は値段の高い MATLAB のクローンの一つでフリーソフト。
超高級電卓として自分のパソコンに入れておく価値あり。
LaTeX や GNU Octave などはすべてタダで手に入るので学生向きと言えるかもしれない。
数値計算ではなく、数式処理をやりたければ MuPAD Light を入れれば良い。

タダですませようと努力するとその分だけ頭を使わなければいけなくなる。
しかし貧乏な学生がタダで何とかするために頭を使い続けることによって
成長するのは非常に良いことだ。
