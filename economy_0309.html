ある小学校にものわかりが悪い子供がいました。
その小学校の校長先生はは、テストの平均点が良いクラスから

　そのためクラスの同級生たちは少年をいつも苛めていました。
「お前のせいでクラスの平均点が下がってしまうんだぞ。」
そういって石つぶてを投げるのです。
　少年はなぜ自分のせいで平均点が下がるのかと理不尽に思いました。
その疑問が少年の心にやどってからというもの朝晩問わず少年はその
問題を考えつづけました。その過程で少年は万有引力の法則を発見しました。
引力によって少年の低い点数に他の人達は引きづられるのだろうか？
最初万有引力の法則がひらめいたとき、問題が解けたと思いました。
　でも翌日になってみると、こじつけであることに気づきました。
さらに考えつづけ少年は平均より自分が低い点数を取ったときには、平均値が
さがるという法則を見つけ出しました。そして少年はたった一人の自分の低い
点数をマージナル（端：限界）と名づけ、クラスの平均より限界が低いとき
平均が下がるという命題を定式化しました。

この少年はレオン・カール・ウィリアム・ワルラス・メンガー・ジェボンズ
Ⅰ世として限界概念発明の父として今ではマルクス経済学者以外の経済学者に
知られています。

40 ：名無しさんの冒険：2007/07/06(Fri) 03:39
T(x)：総費用
M(x)：限界費用
A(x)：平均費用

M(x) = d/dx(T(x))
A(x) = T(x)/x

T(x)は単調増加とする…M(x) > 0
xが十分大きいとき、T(x)は下に凸とする…d/dx(M(x)) > 0

d/dx(A(x)) = (x M(x) - T(x))/x^2
d/dx(x M(x) - T(x)) = x d/dx(M(x)) で、これは仮定より正。

したがって A(x)はxの値が a M(a) - T(a) = 0 すなわち M(a) = T(a) / a = A(a)
をみたすaであるとき最小値をとる。

ゆえに、A(x)とM(x)の交点(a, M(a))においてA(x)は最小値をとる。
また、このとき原点から(a, T(a))に引いた直線の傾きはM(a)となるので、この直線は
T(x)と接する。
