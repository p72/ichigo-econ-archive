16 ：名無しさんのマーチ：2001/03/02(Fri) 19:33
シミュレーションと書くとだれもがモンテカルロですかと尋ねます。
モンテカルロは、MathematicaPrimerという本（訳：オーム社）
でその名のついた節しか読んだことありません。
そこには、49/100で負け-1の損失, 51/100で勝ち+1を得られるとします。
n回掛けを行い、合計の利益がでます。これが一回のゲームです。
　このゲームをｋ回行います。すると、ｋ、ｎを適当に選ぶことで
ほとんどゼロより大の利益を得ることができます。つまり、n回合計の
利益が負となる可能性はｋ回ゲームを繰り返すなかで、ほとんど起こらないの
です。そんなｋとｎがあるのだということをシミュレーションでやっていました。

僕が考えているシミュレーションは、非線型な式が与えられたときその解は
パラメーターが代わるときどういうふうに変わるだろうかということです。
代数的に解けない場合はシミュレーションに頼ることになります。論文
そんなことをやっているものがあるのですが、それを再現して図を書いてみたいと
思ってもどうもうまくいかないのです。FindRootをするとエラーが生じる。
つまりニュートン法では解が求められない場合もありどうしようかということです。

行列計算の違い。

例．２つの2x2行列を、

A = 1 2
　　 3 4

B = -1 3
　　 -2 1

とする。すると、ここで、

>> C = A * B;

は、c(i,j)=Σa(i,k)b(k,j) をあらわす。つまり、AとBの行列積

C =　-5　5
　　 -11 13

一方、

>> C = A .* B;

は、c(i,j)=a(i,j)b(i,j)、つまり、要素積

C = -1 6
　　 -6 4

例えば、Aの1行1列目の1とBの1行1列目の-1を掛けたものがCの1行1列目と
なるから-1。

あと、MATLABでは行列とスカラーの足し算なんてできちゃうから注意が必要です。
